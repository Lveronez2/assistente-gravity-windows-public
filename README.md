# Assistente Gravity para Windows

Cliente experimental para localizar arquivos em pastas escolhidas no Windows, com interface Liquid Glass.

## Código-fonte

O pacote versionado desta cópia pública está em [`assistente-gravity-windows-public.zip`](./assistente-gravity-windows-public.zip). Ele contém código, recursos e documentação de primeiro uso. O histórico de desenvolvimento e o repositório de trabalho permanecem privados.

## Primeiros passos

1. Baixe e extraia o ZIP.
2. Leia `docs/PRIMEIRO-USO.md` e instale os pré-requisitos indicados.
3. Execute `start-windows.cmd`.

Esta versão é uma prévia para Windows; consulte os requisitos e limitações da documentação antes de usar em produção.
